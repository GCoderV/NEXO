Novedad de esta copia (fase6-4): un proyecto nuevo YA NO asume nada del proyecto anterior. Al crear o abrir otro proyecto se borran el recibo del agente, el apartado seleccionado, los límites del modo agente, los permisos de búsqueda, los consentimientos y el texto pendiente: cada proyecto empieza verdaderamente en blanco (los datos guardados del proyecto anterior se conservan al volver a abrirlo). Esto corrige el caso en que el bot parecía seguir trabajando con la universidad, población o método de la tesis previa. También siguen corregidos: el agente continuo no rellena Conclusiones sin datos (pregunta por el corpus; fase6-3) y Copilot no se cierra tras capturar la sesión (fase6-2) —déjalo abierto mientras uses la cuenta—. Se mantienen el agente continuo sin cuota de pasos, la búsqueda de fuentes en Crossref y la pestaña Documento (Markdown, HTML y DOCX sin Word ni internet). Para confirmar que abres esta copia: ejecuta VERIFICAR.cmd y comprueba que dice (fase6-4) y las siete líneas OK, incluidas «Datos empiricos: OK» y «Aislamiento de proyectos: OK». Si no aparecen, estás usando una carpeta antigua.

  • O haz clic derecho sobre Descargar el ZIP → Guardar enlace como….
  • O abre descargar-nexo-tesis.html directamente en tu navegador (doble clic) y pulsa el botón.

Para usarlo en Windows

  1. Descomprime todo el contenido en una carpeta vacía (no lo ejecutes desde dentro del ZIP).
  2. Haz doble clic en INICIAR-TESIS.cmd: se autoverifica y abre la aplicación.
  3. Requiere Python 3.11+ con Tkinter y SQLite (el instalador de python.org ya los incluye). No hay que instalar dependencias: websocket y pypdf van incluidos.
  4. En la pestaña Documento pulsa Generar documento completo para obtener .md, .html y .docx, o Completar lo que falta para lanzar el agente.
Importante: es un build de desarrollo, no una release publicada ni una versión validada con Microsoft. La continuidad real de Copilot, Word COM, DPAPI y la apertura del DOCX en Word aún no se han comprobado en este entorno. El DOCX es OOXML estándar validado estructuralmente; verifícalo en tu Word. Prueba primero con un proyecto sin datos personales. No pegues tokens ni URLs autenticadas.
