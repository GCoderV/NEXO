El presupuesto de reintentos se reinicia en cada paso del bucle (antes se agotaba en el séptimo con «No quedan rutas listas…»), y Copilot espera hasta 180 s por respuesta en vez de 90 s, para que un apartado largo no se corte a la mitad. Para usarlo en Windows

  1. Descomprime todo el contenido en una carpeta vacía (no lo ejecutes desde dentro del ZIP).
  2. Haz doble clic en INICIAR-TESIS.cmd: se autoverifica y abre la aplicación.
  3. Requiere Python 3.11+ con Tkinter y SQLite (el instalador de python.org ya los incluye). No hay que instalar dependencias: websocket y pypdf van incluidos.
  4. En la pestaña Documento pulsa Generar documento completo para obtener .md, .html y .docx, o Completar lo que falta para lanzar el agente.
Importante: es un build de desarrollo, no una release publicada ni una versión validada con Microsoft. La continuidad real de Copilot, Word COM, DPAPI y la apertura del DOCX en Word aún no se han comprobado en este entorno. El DOCX es OOXML estándar validado estructuralmente; verifícalo en tu Word. Prueba primero con un proyecto sin datos personales. No pegues tokens ni URLs autenticadas.
